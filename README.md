# 💻 OIBSIP Internship Tasks : Level-2

This repository contains a collection of **4 web development tasks** completed as part of my internship. These projects demonstrate my understanding of **HTML, CSS, JavaScript, and Node.js** through practical implementations.

---

## 🚀 Projects Included

### 🔢 Task 1: Calculator

A fully functional calculator that performs basic arithmetic operations.

**Features:**

* Addition, subtraction, multiplication, division
* Interactive UI with button-based input
* Real-time display updates

**Tech Used:**

* HTML
* CSS
* JavaScript

---

### 👤 Task 2: Tribute Page

A responsive tribute page dedicated to an inspiring personality.

**Features:**

* Structured content layout
* Image integration
* Styled typography and design

**Tech Used:**

* HTML
* CSS

---

### ✅ Task 3: To-Do Web App

A simple task management application for daily productivity.

**Features:**

* Add, edit, and delete tasks
* Mark tasks as completed
* Separate sections for Pending & Completed tasks

**Tech Used:**

* HTML
* CSS
* JavaScript

---

### 🔐 Task 4: Login Authentication System

A basic authentication system with backend integration.

**Features:**

* User registration and login
* Protected dashboard access
* Backend server handling requests

**Tech Used:**

* Node.js
* Express.js
* HTML
* CSS
